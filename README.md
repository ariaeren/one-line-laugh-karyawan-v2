A single-sentence entry for "The One-Line Laugh": one quiet, everyday observation with a late twist, written with Node 22 and no dependencies beyond the standard library.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` (default `/output`).
